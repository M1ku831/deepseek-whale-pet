# 这个文件夹为什么是空的？

按照原项目 [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)
的 PROVENANCE.md 声明，其 assets 素材（图片/音效）**不在 MIT 许可范围内、不授予再许可**，
所以本仓库不能包含这些文件（桌面版上游 [comreade-123/DeepSeek-Whale-widget-desktop](https://github.com/comreade-123/DeepSeek-Whale-widget-desktop) 亦未获得素材授权）。

想本地运行好感版，请自行把下列文件放入本目录（可从上述两个上游官方发布的完整程序中获取，仅限个人使用）：

- `DSniang1.png`、`DSniang02.png` —— 鲸鱼娘立绘（必需，没有会隐身）
- `rua.gif` —— 摸头动图
- `D1.mp3`、`D2.mp3`、`Ya1.mp3`、`Ya2.mp3` —— 互动音效（可缺省）

也可以放自己画的同名图片/音效替换。
